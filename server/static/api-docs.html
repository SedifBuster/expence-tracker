GET /ailocal
Получить список всех пользователей (пагинация, фильтры)

Описание: Возвращает массив объектов пользователей.

Query params: page, limit, sort, role

Пример запроса (cURL)
curl -X GET "https://api.yourdomain.com/v1/users?page=1&limit=10" \ -H "Authorization: Bearer {token}"
Пример ответа (200 OK)
{ "data": [ { "id": 1, "name": "Алексей", "email": "alex@example.com", "role": "admin" } ], "total": 42, "page": 1 }
POST /users
Создание нового пользователя

Тело запроса (JSON): name, email, password, role (опционально)

Пример запроса
curl -X POST "https://api.yourdomain.com/v1/users" \ -H "Content-Type: application/json" \ -d '{"name":"Мария","email":"maria@test.com","password":"secure123"}'
Ответ 201 Created
{ "id": 124, "name": "Мария", "email": "maria@test.com", "createdAt": "2025-04-07T10:30:00Z" }
